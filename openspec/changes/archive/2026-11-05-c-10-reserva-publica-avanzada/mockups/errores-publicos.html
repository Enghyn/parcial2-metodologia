Estados de error del portal público

Catálogo de respuestas que el paciente puede ver. Los códigos HTTP son 409/429/404; el mensaje siempre explica qué pasó y qué hacer.

409 · El horario se ocupó

Ese horario ya no está disponible

Elegí otro horario para continuar con tu reserva.

HTTP 409 · código: conflict

409 · La retención venció

Tu reserva temporal venció

El horario se liberó para otros pacientes. Volvé a elegir un turno.

HTTP 409 · código: retention_expired · también cuando el token no coincide o ya fue consumido.

429 · Demasiadas solicitudes

Estás yendo muy rápido

Esperá un momento antes de volver a intentar.

42
segundos restantes

Se reanuda automáticamente (Retry-After).

HTTP 429 · código: rate_limited · header Retry-After en segundos.

404 · Turno no encontrado

No encontramos ese turno

El enlace puede estar mal copiado o el turno ya no existe. Volvé a reservar.

HTTP 404 · código: not_found · el token es opaco y no filtra datos del paciente.

422 · Datos inválidos

Revisá los campos

Nombre completo, DNI y teléfono son obligatorios.

HTTP 422 · código: validation_error · extra='forbid' rechaza campos no declarados (R1).
